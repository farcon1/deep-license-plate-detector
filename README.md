# Deep License Plate Detector: общее описание проекта

## 1. Общая характеристика

Deep License Plate Detector — программно-экспериментальная система автоматического обнаружения и распознавания автомобильных номерных знаков на изображениях. Проект разработан в рамках магистерской выпускной квалификационной работы и объединяет методы глубокого обучения, компьютерного зрения, экспериментальной оценки качества и контейнеризированного развертывания.

Система реализует полный ALPR-пайплайн:

```text
Изображение автомобиля
    ↓
Детекция области номерного знака
    ↓
Нормализация и вырезание crop-области
    ↓
OCR-распознавание символов номерного знака
    ↓
Визуализация и структурированный вывод результата
```

Проект ориентирован на воспроизводимое исследование и практическую демонстрацию: в репозитории представлены модули подготовки данных, обучения, оценки, инференса, web-интерфейса и Docker-контейнеризации.

## 2. Цель проекта

Цель проекта — разработать и экспериментально обосновать систему детекции и распознавания автомобильных номерных знаков на изображениях с применением глубоких нейронных сетей, устойчивую к вариативности условий съёмки и пригодную для демонстрационного прикладного использования.

## 3. Основные задачи

В рамках проекта решаются следующие задачи:

1. Анализ предметной области автоматического распознавания автомобильных номерных знаков.
2. Подготовка датасета CCPD2019 для задач детекции и OCR.
3. Реализация базового компьютерно-зрительного подхода для сравнения с нейросетевой моделью.
4. Подготовка YOLO-датасета для обучения детектора номерных знаков.
5. Обучение нейросетевой модели детекции номерных пластин.
6. Формирование OCR-датасета на основе координат номерного знака и текстовой разметки.
7. Обучение OCR-модели для распознавания семисимвольной строки номера.
8. Улучшение OCR за счёт робастного формирования crop-изображений.
9. Интеграция детектора и OCR в единый end-to-end pipeline.
10. Разработка web-интерфейса и REST API для демонстрации инференса.
11. Контейнеризация infer- и train-контуров через Docker.
12. Экспериментальная оценка качества отдельных компонентов и всей системы.

## 6. Используемые данные

Основным датасетом является CCPD2019. Аннотация в CCPD закодирована непосредственно в имени файла и содержит:

- координаты bounding box номерной пластины;
- координаты четырёх углов номерного знака;
- индексы символов номерного знака;
- дополнительные признаки яркости и размытости;
- параметры наклона.

Такой формат позволяет использовать один и тот же набор данных для двух связанных задач: детекции номерного знака и OCR-распознавания текстовой строки.

## 7. Детекция номерных знаков

Для детекции номерных пластин используется YOLO-модель. Датасет предварительно экспортируется в YOLO-формат, где каждый номерной знак представлен одним классом `license_plate`.

Основные параметры финальной конфигурации детектора:

| Параметр | Значение |
|---|---:|
| Архитектура | YOLO11n |
| Размер входа | 960 |
| Количество классов | 1 |
| Класс | license_plate |
| Основная метрика | IoU, AP, precision, recall |

Детектор отвечает за локализацию номерной пластины на исходном изображении. В end-to-end режиме выбирается наиболее уверенный bbox-кандидат, после чего соответствующая область передаётся в OCR-модуль.

## 8. OCR-распознавание

OCR-модуль решает задачу распознавания семисимвольной строки номерного знака. Используется модель ResNet34 с несколькими независимыми классификационными головами. Каждая голова соответствует фиксированной позиции символа.

Финальная OCR-модель была обучена на робастном датасете, включающем различные варианты crop-изображений: перспективно выровненные crop по углам, bbox crop, bbox crop с padding и синтетически смещённые bbox crop. Это повышает устойчивость модели к ошибкам локализации, возникающим после работы детектора.

Основные параметры финального OCR-эксперимента:

| Параметр | Значение |
|---|---:|
| Архитектура | ResNet34 |
| Размер входа | 320 × 96 |
| Количество эпох | 50 |
| Batch size | 96 |
| Learning rate | 0.0005 |
| Weight decay | 0.0001 |
| Лучшая зафиксированная val full-accuracy | 0.9936 |
| Финальная val full-accuracy | 0.9931 |
| Финальная val char-accuracy | 0.9990 |

## 9. End-to-end pipeline

Итоговый pipeline объединяет детектор и OCR-модель:

1. Пользователь загружает изображение автомобиля.
2. YOLO-детектор определяет область номерного знака.
3. Bounding box ограничивается границами изображения.
4. Crop номерного знака передаётся в OCR-модель.
5. OCR-модель предсказывает семь символов номерной строки.
6. Система возвращает текст номера, confidence, bbox, crop и изображение с визуализацией.

Такое разделение на два этапа повышает интерпретируемость системы: ошибки можно анализировать отдельно для детекции и отдельно для OCR.

## 10. Web-интерфейс и API

Проект содержит встроенный web-интерфейс на FastAPI. Интерфейс позволяет:

- загрузить изображение автомобиля;
- выбрать режим работы;
- настроить confidence threshold, IoU и image size детектора;
- получить распознанный номер;
- увидеть исходное изображение, изображение с bbox и crop номерного знака;
- посмотреть численные значения confidence и координаты bbox.

Поддерживаемые режимы:

| Режим | Назначение |
|---|---|
| Детекция + OCR | Полная обработка изображения |
| Только детекция номера | Диагностика качества локализации |
| Только OCR по crop номеру | Проверка OCR на заранее вырезанном номере |

REST API доступен через endpoint:

```text
POST /api/predict
```

Health-check endpoint:

```text
GET /health
```

## 11. Docker-контейнеризация

Проект поддерживает контейнеризированный запуск через Docker Compose. Предусмотрены два сервиса:

| Сервис | Назначение |
|---|---|
| `infer` | Запуск FastAPI web-интерфейса и API |
| `train` | Среда для обучения и экспериментальных пайплайнов |

Команда запуска infer-сервиса:

```bash
docker compose up --build infer
```

После запуска web-интерфейс доступен по адресу:

```text
http://localhost:8000
```

Контейнеризация обеспечивает воспроизводимость окружения, упрощает демонстрацию системы и отделяет infer-зависимости от train-зависимостей.

## 12. Экспериментальная значимость

Проект демонстрирует полный цикл разработки computer vision-системы:

- анализ и подготовка данных;
- реализация baseline-подхода;
- обучение нейросетевого детектора;
- обучение OCR-модуля;
- повышение устойчивости OCR через робастную генерацию crop-изображений;
- оценка качества по независимым метрикам;
- интеграция моделей в end-to-end приложение;
- контейнеризация и воспроизводимый запуск.

Научно-практическая ценность проекта заключается в сравнении классического и нейросетевого подходов, обосновании выбора архитектуры детекции и демонстрации влияния способа формирования OCR crop-изображений на устойчивость распознавания.

## 14. Заключение

Deep License Plate Detector представляет собой завершённый прототип системы автоматического обнаружения и распознавания автомобильных номерных знаков. Проект объединяет исследовательскую часть, экспериментальную оценку качества и инженерную реализацию infer-сервиса. Использование YOLO-детектора и робастно обученной OCR-модели позволяет решать задачу распознавания номерного знака в полном end-to-end режиме, а Docker-контейнеризация обеспечивает воспроизводимый запуск системы в изолированном окружении.
